## Описание программы
ПО для приложения discord помогающее более вариативно настраивать активность в профиле и выбирать произвольные приложения.
### Необходимые условия
Что нужно для ПО и как его установить
**Python версия 3.8 или выше**
**Windows 10, 11**
Установка: скачайте архив, распакуйте в удобную папку, запустите файл start.bat, нажмите пробел.
